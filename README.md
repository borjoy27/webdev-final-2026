# webdev final 2026 - TGrade

## 1. 프로젝트 개요
- **주제**: 진위·예상 등급 분석을 결합한 웹 기반 TCG 수집·거래 서비스
- **브랜드명**: TGrade[티-그레이드 · Trade의 교환·거래와 Grade의 등급·진위를 결합]
- **타깃**: 포켓몬 TCG 카드를 수집하는 사용자
    - **기존 수집가**: 공식 감정을 의뢰할 카드를 사전에 선별하고 컬렉션을 체계적으로 관리 및 거래하려는 사용자
    - **TCG 입문자**: 높은 감정 비용을 부담하지 않고도 보유 카드의 대략적인 등급과 진위를 파악하며 수집·거래를 시작하려는 사용자

본 프로젝트는 포켓몬 TCG 카드를 수집하는 사용자를 위한 웹 기반 TCG 카드 수집 및 교환 플랫폼 개발을 목표로 한다.

사용자는 카드 이미지를 업로드하여 공식 감정을 맡기기 전 카드의 예상 등급과 가품 의심 여부를 확인할 수 있다. 분석이 완료되면 사용자의 도감에 등록된다. 등록된 카드를 다른 사용자의 카드와 교환하거나 판매할 수 있는 중고 거래 기능을 제공한다.

다른 플랫폼과 차별점으로 카드의 예상 등급 및 가품 의심 여부와 거래자의 도감 등록 현황을 중고 거래 과정에서 참고할 수 있는 정보로 활용하고자 한다. 이를 통해 거래 시 카드 분석 결과를 확인할 수 있도록 하여 사용자의 합리적인 판단 환경을 구축하는 것을 목표로 한다.

최종 목표로 본 플랫폼은 카드 예상 등급 산출, 도감 현황 관리, 사용자 간 거래까지 하나의 서비스로 제공하여 포켓몬 TCG 수집 및 거래의 편의성을 높이고자 한다.

### 구현 범위 및 제외 사항
- **구현 범위 (이번 기말 프로젝트)**
  - 메인, 문의 2페이지 반응형 브랜드 웹사이트 및 화면 인터랙션
  - 카드 등급·진위 판별 콘셉트, 도감/수집률 UI, 거래 신뢰 포인트 소개 섹션
  - 다크모드 토글, 모달 열기/닫기, 문의 폼 유효성 검사 및 제출 성공 모달, 선택 라이브러리 기능 구현
- **제외 범위 (미구현 / 추후 확장)**
  - 회원 인증(로그인/회원가입), 실제 카메라/AI 등급·가품 판별 처리, 도감·거래·에스크로·정산 데이터베이스 연동
  - 장바구니·결제 기능 및 문의 폼의 실제 외부 서버 전송 처리
